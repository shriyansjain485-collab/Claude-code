# Content calendar

1. Read `brand/personal.md`, `brand/company.md`, the existing
   `content/calendar.md`, `content/ideas/`, recent `content/published/`, and
   the latest `reports/review-*.md` if any.
2. Ask the owner (one short question set) for anything happening in the period:
   launches, events, hires, milestones, travel, things they're learning.
3. Plan `$ARGUMENTS` weeks (default 2) using each profile's platform cadence:
   - Spread pillars per each profile's mix; no pillar twice in a row on a platform.
   - Mix formats: text, carousel/document, image, short video, thread, poll.
   - Coordinate the brands: company news is announced by the company account
     first; the founder's post adds the personal story behind it a few hours or a
     day later. Never post identical copy on both.
   - Leave 1 open slot per week for reactive/timely posts.
4. Write `content/calendar.md` as a table:

   | Date | Time | Brand | Platform | Pillar | Format | Idea / hook | Status |

5. Ask whether to draft the posts now. If yes, use the `content-creator`
   agent (in parallel for independent posts) to write each into `content/drafts/`.
